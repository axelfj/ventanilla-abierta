# Ventanilla Abierta

**La ventanilla que nunca cierra. Sin fila.**

Ventanilla Abierta es un proyecto de código abierto que explica, en español claro, cómo hacer trámites legales y administrativos en Costa Rica. Es gratis, sin anuncios y hecho por la comunidad.

## También

- **[Alertas](alertas/)**: cortes de luz programados, avisos del clima y sismos, con enlace al aviso oficial.
- **[Buses](buses/)**: cuánto cuesta cada ruta según la ARESEP, y dónde ver los horarios.

## Para qué sirve

- **Trámites que podés hacer solo:** la guía te lleva de principio a fin.
- **Trámites que necesitan notario o abogado:** la guía no reemplaza al profesional, pero te ayuda a llegar preparado: qué documentos llevar, cuánto cuesta oficialmente, cuánto tarda y qué preguntar.

## Reglas del proyecto

1. **Nunca inventamos.** Cada dato lleva su fuente oficial y la fecha en que se verificó.
2. **Es información, no asesoría legal.**
3. **Lenguaje claro**, en español con voseo.
4. **No recomendamos** despachos, empresas ni servicios pagos.
5. **Todo es gratis**: el sitio corre en GitHub Pages, sin dominio pago ni servidores.

## Cómo está organizado

```
tramites/costa-rica/          Índice y guías por categoría
plantillas/ficha-tramite.md   Formato estándar de cada guía
.github/ISSUE_TEMPLATE/       Plantillas para reportar correcciones o pedir trámites
```

Cada guía sigue la misma ficha: qué es, si se puede hacer solo, requisitos, costos oficiales, pasos, tiempos, errores comunes, preguntas frecuentes y fuentes.

## Cómo ayudar

- ¿Encontraste un dato viejo o un error? Abrí un issue de **Corrección**.
- ¿Querés que expliquemos un trámite? Abrí un issue de **Nuevo trámite**.
- ¿Querés escribir una guía? Leé [CONTRIBUTING.md](CONTRIBUTING.md).

## Hacia dónde vamos

- **Fase 1:** guías de trámites de Costa Rica, incluido un kit legal para artistas.
- **Fase 2:** alertas locales (agua, luz, carreteras) y horarios y rutas de buses de Costa Rica y Centroamérica.
- **Más adelante:** un asistente conversacional que siga siendo gratis para el proyecto (con tu propia API key o con un modelo abierto que corra en tu navegador).
